# 證件照製作（純前端、免費、免部署後端）

這是一個完全在瀏覽器端運作的證件照工具，照片全程留在你自己的裝置上，不會上傳到任何伺服器。

## 功能

- 手機瀏覽器直接拍照（Android/iOS Chrome、Safari 皆可），或從相簿上傳
- AI 自動去背並套用標準底色（紅／藍／白／灰／自訂）
- 依台灣官方規格製作證件照：身分證/護照/台胞證（3.5×4.5cm）、健保卡/國際駕照/學生證（4.2×4.7cm）、1吋（2.8×3.5cm）、美簽、日簽等，也可自訂 mm 尺寸
- 裁切畫面會畫一層**白色虛線頭部對齊框**（頭頂線＋下巴允許範圍＋臉部橢圓），對照官方規定的頭長比例即時顯示，方便對準
- 修圖工具（參考美圖秀秀風格的美顏流程）：
  - **智慧磨皮**：邊緣保留式柔膚，只柔化平坦的皮膚，眼睛、頭髮、嘴唇等五官邊緣保留清晰，不會整臉變模糊
  - **美白提亮**：用膚色遮罩只提亮皮膚，不會把背景或頭髮染色
  - **紅潤氣色**：替膚色加一點暖色調，讓氣色更好
  - **銳化清晰**：最後用 unsharp mask 讓五官恢復銳利
  - 另外還有縮放、亮度、對比可調
- 自動排版：預設把證件照滿版塞進 **4×6 吋相紙**（152×102mm，超商沖印最常見的規格），也可以選 5 寸相紙或 A4 紙，附裁切線，下載後直接送洗

## 去背引擎（本機 AI，免費、免設定）

使用開源套件 [@imgly/background-removal](https://github.com/imgly/background-removal-js)，透過 CDN 在使用者瀏覽器內以 WebAssembly 執行 AI 模型，完全免費、無使用次數限制。第一次使用時瀏覽器需要下載模型檔案（幾 MB～數十 MB，依「快速／高品質」模式而定），下載後瀏覽器會快取；模型和照片都不會離開你的裝置。

> 早期版本曾提供一個選用的 Gemini API 去背選項，因為本機瀏覽器 AI 已經很好用，且需要額外部署後端與 API 金鑰，已移除。現在只用本機 AI 去背，開箱即用。

## 本機測試

不需要安裝任何後端伺服器，用任意靜態伺服器打開 `index.html` 即可：

```bash
cd id-photo-app
python3 -m http.server 8000
# 瀏覽器打開 http://localhost:8000
```

（不能直接用 `file://` 開啟，因為相機權限與 ES module 在部分瀏覽器下需要 http/https 網址。）

## 免費部署

任選一個免費靜態網站服務即可（不需要任何後端 / 環境變數）：

### 方法一：Cloudflare Pages
1. 到 https://pages.cloudflare.com 註冊（免費）
2. 建立新專案 → 連結 GitHub repo（或「直接上傳」把 `index.html`、`style.css`、`app.js` 這幾個檔案上傳）
3. 幾秒後就會拿到一個 `xxx.pages.dev` 的網址，手機直接開就能用

### 方法二：Netlify Drop
1. 到 https://app.netlify.com/drop
2. 直接把 `index.html`、`style.css`、`app.js` 拖進網頁裡，立刻部署，拿到 `xxx.netlify.app` 網址

### 方法三：GitHub Pages
1. 把 `index.html`、`style.css`、`app.js` push 到一個 GitHub repo
2. Repo 設定 → Pages → Source 選 main branch，儲存
3. 幾分鐘後可用 `https://你的帳號.github.io/repo名稱/` 開啟

以上都是免費方案，長期使用不用錢，沒有流量或用量限制的疑慮（除非流量非常大）。

## 注意事項

- 尺寸與頭部對齊虛線框已依台灣官方公告（內政部戶政司國民身分證相片規格、外交部領事事務局晶片護照相片規格）設定頭長 3.2〜3.6cm、臉部占比 70%〜80% 等數字；但這個工具沒有做嚴格的自動法規驗證（例如沒有真的偵測五官位置），排版與尺寸僅供對齊參考，正式證件申請前請自行核對受理單位最新規定。
- 磨皮／美白／紅潤等美顏效果請適度使用；部分證件（如護照）規定不得過度修圖或改變本人樣貌，避免因修圖過頭而不被受理。
- 修圖是即時預覽用縮圖（反應快），按「完成，下一步排版」時才會用全解析度重算一次套用到最終輸出圖片，確保下載的證件照是最高畫質。
